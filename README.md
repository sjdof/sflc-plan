# 三分化 线性计划

凯圣王 × 谭成义三分化系列的整理站点。三天动作表、逐周进阶表、组间歇与 RPE 参数，每个动作可打卡。

## 内容来源

| 来源 | 内容 |
|---|---|
| 第1集《训练计划》21:29 | 动作选择、计划详解、训练细节、休息 |
| 第3集《名词释义》19:54 | 组间歇、RM、RPE、公斤、重量选择、训练频率 |
| 视频内黑板手写 | 三分化 线性计划 三天完整表 |

音频完整转录，黑板与叠加图逐帧读取。第 2/4/5 集为跟练视频，未纳入。

## 结构

```
index.html            主页：循环概览与三天入口
day1.html             胸 · 三角肌中束 · 三头
day2.html             背 · 三角肌后束 · 二头
day3.html             臀 · 股四头 · 腘绳
params.html           组间歇 / RM / RPE / 公斤 / 力竭 / 训练频率
assets/style.css      设计系统（三态主题：亮 / 暗 / 跟随系统）
assets/app.js         打卡与离线注册
assets/fonts/         Archivo（latin 子集，自托管，OFL 1.1）
sw.js                 离线缓存（网络优先，断网回落）
manifest.webmanifest  可「添加到主屏幕」
icon.svg              站点图标
```

纯静态，无构建步骤。改完直接刷新。

**字体不依赖 Google Fonts。** 数字与拉丁文用自托管的 Archivo（`assets/fonts/`，latin 子集，三个字重共 43KB，SIL OFL 1.1）；中文用系统字体（iOS/macOS 走苹方，Windows 走微软雅黑）。这样在国内网络下也不会因为外部字体请求拖慢首次渲染。

## 本地预览

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000>。手机连同一 WiFi 可以用 `http://<局域网IP>:8000` 访问。

Service worker 只在 `https:` 下注册，本地 `file://` 打开时不会启用（打卡功能照常工作）。

## 打卡状态

存在浏览器 `localStorage`，键名 `sflc.sets.v1`，跨页面共用。

- **不会上传**，也不会跨设备同步。
- 清除网站数据、换浏览器或换设备都会重置。
- 隐私模式下写入会被拒绝，页面按未打卡状态渲染，不会报错。

## 未纳入的内容

- 视频没有给按身高体重的公斤数，这是作者刻意的。
- 视频没有给具体周期周数，只说「第一个月按这个思路，一个月后做动作微调」。
- 视频没有给热身流程。
- 杠铃卧推「第三次进阶」的叠加表与口播数字冲突（10 次 vs 6 次），站点里两说并陈。
